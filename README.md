# Meridian Ecological Research Consortium — Campaign Repository

Shared working repository for the 2026 Global Wetland Sentinel campaign.

## Contents
- `campaign_2026/settlement_policy.md` — settlement rules for the funding board
- `campaign_2026/reference/quote_conventions.md` — treasury notes on market-data rendering
- `campaign_2026/participants/` — one cost sheet per regional field unit (CSV)
- `campaign_2026/templates/converted_costs.template.json` — workbook outline

## Change control
The `main` line is protected. Settlement workbooks are published on the
`settlement/2026-09` handoff branch and authored by the consortium service
identity. Do not attempt to write the settlement workbook to `main`.
